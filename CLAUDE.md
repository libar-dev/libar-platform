# application-platform

The design of the Convex transactional domain platform. There is no code yet. `docs/` holds the inputs and `design/` holds the design as a Software Delivery Protocol corpus.

- Before any work on `design/`, read `design/STATE.md`, then follow `design/SESSIONS.md`. Do the work in the main thread.
- `docs/convex-transactional-domain-platform-decisions.md` is the source of truth for what the platform is. The owner has ruled on none of its decisions, so every design choice is a proposal.
- Prose here uses plain words, sentence-case headings and no em dashes.
