## The owner's answer

Admin access is the authority of an operation over the whole deployment. Every operator entry is an internal function, so only admin access reaches it. It takes the operator as a required argument, a string bounded as an actor's ID is, refuses an empty one, reads no grant, and writes that operator on what it changes: the generation row, the gate's audit record, the restore's run record. The Specs say "records the stated operator" and stop saying "authorizes an operator actor". No scope beyond the tenant is added. D11's one trusted deployment is the boundary, and the Spec says a stated operator is what admin access chose to state.
