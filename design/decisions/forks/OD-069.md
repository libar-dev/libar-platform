**The corpus shows.** The contract spans all tenants and gives the registry no tenant dimension; read-model rows and markers still name tenants. ## The owner's answer

One generation per read model spans every tenant. The generation registry is operational data of the deployment and its indexes lead with the read model. Every table that holds tenant data, the read-model rows and the markers among them, still leads with the tenant. The deviation from Law 11's index rule is recorded where it is today, as confirmed. A rebuild for one tenant is not offered.
